
# Netflix Analysis Dashboard

## Project Overview
This project analyzes Netflix movies and TV shows data using Power BI.  
The dashboard provides insights into content distribution, ratings, genres, release trends, and country-wise availability.

## Objectives
- Analyze Netflix content trends
- Compare Movies vs TV Shows
- Identify top genres and ratings
- Study yearly content growth
- Visualize country-wise content distribution

## Tools & Technologies
- Power BI
- Excel / CSV Dataset
- Power Query
- DAX

## Dataset Information
The dataset contains information about Netflix titles including:
- Title
- Type (Movie/TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre

## Data Cleaning Steps
- Removed null values
- Changed data types
- Cleaned duplicate records
- Split multi-value columns
- Formatted dates properly

## Dashboard Features
- KPI Cards
  - Total Titles
  - Total Movies
  - Total TV Shows
  - Total Countries

- Visualizations
  - Movies vs TV Shows
  - Top Genres
  - Ratings Distribution
  - Content by Release Year
  - Country-wise Content Map
  - Top Directors

## Key Insights
- Movies are higher in number compared to TV Shows.
- Most Netflix content was added after 2015.
- Drama and Comedy are the most popular genres.
- The United States has the highest amount of Netflix content.
- TV-MA is the most common content rating.

## Project Workflow
1. Data Collection
2. Data Cleaning using Power Query
3. Data Modeling
4. Creating DAX Measures
5. Dashboard Design
6. Insight Generation

## Conclusion
This dashboard helps understand Netflix content trends and provides interactive visual analysis for better decision-making.
